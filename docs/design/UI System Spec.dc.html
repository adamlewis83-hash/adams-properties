5 · Money formatting

· Tabular numerals (font-variant-numeric: tabular-nums), right-aligned in tables. · Compact in cards and tight spaces: $750k · $1.75M — never a truncated "$750,00…". · Full precision only in ledgers and statements: $1,750,000.00. · Color only for meaning: Pine = positive/income, Brick = negative/past-due.
